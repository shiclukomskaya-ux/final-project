Дипломный проект: Веб-планировщик задач (ToDo List)

Описание проекта:

Проект представляет собой веб-сервер для планирования и управления задачами. Написана на языке Go (Golang) с использованием базы данных SQLite для хранения данных.

Разработанный REST API обеспечивает:
- Добавления, редактирования и удаления задач.
- Просмотра списка задач.
- Автоматический пересчёт даты для повторяющихся задач.


Выполненные задания повышенной сложности (со звёздочкой)
Создание и сборка Docker-образа (создан и протестирован Dockerfile).


Инструкция по локальному запуску проекта (без Docker)

1. Сборка исполняемого файла в корень проекта:
   
   go build -o app.exe main.go

2. Запуск скомпилированного сервера:
   
   ./app.exe 

3. Адрес в браузере:
   После старта сервер по умолчанию принимает входящие запросы на порту 7540. Открывать планировщик по адресу: http://localhost:7540

   



Инструкция по запуску контейнера (Docker):

Сборка выполнена на базе официального образа Go.

1. Сборка Docker-образа:

   docker build -t todo-app .


2. Запуск контейнера:
   Запуск контейнера в фоновом режиме с пробросом рабочего порта веб-сервера:
   
   docker run -d -p 7540:7540 todo-app
